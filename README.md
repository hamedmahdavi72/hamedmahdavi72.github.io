# hamedmahdavi72.github.io

Personal site. No framework, no build step for the HTML itself.

- `index.html` is generated: edit `generator/content.py`, then run `python3 generator/build.py`.
- `CV.pdf` is the web version of the resume (built from `resume-web.tex` in the resume repo).
- `dist/assets/img/` holds the portrait, favicon, and the pixel sprite used by the easter egg.
